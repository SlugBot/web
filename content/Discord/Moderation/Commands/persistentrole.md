# `/persistentrole`
*Module: [[Moderation]]*<br>
Add or remove persistent roles
## /persistentrole add
`/persistentrole add <role>`<br>
Add persistent role
#### role
role to make persistent
- Type: `ROLE`
- Required: `TRUE`
## /persistentrole remove
`/persistentrole remove <role>`<br>
Remove persistent role
#### role
Remove role as persistent
- Type: `ROLE`
- Required: `TRUE`
## /persistentrole list
`/persistentrole list`<br>
List all persistent roles in this guild
