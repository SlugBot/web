# `/compromise`
*Module: [[Economy]]*<br>
Attempt to compromise a target's stat
## `/compromise <target> <stat>`
#### target
Target user to compromise
- Type: `USER`
- Required: `TRUE`
#### stat
Stat to compromise
- Type: `SELECTION`
  - `firewall`
  - `bypasser`
  - `encryption`
  - `cracker`
  - `scanner`
  - `interceptor`
  - `wire`
  - `injector`
- Required: `TRUE`
