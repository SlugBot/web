# `/rootkit`
*Module: [[Economy]]*<br>
Enable or disable ROOTKIT mode. A ROOTKIT allows the control of another user's account
## /rootkit enable
`/rootkit enable <target>`
Enable ROOTKIT mode
#### target
User you have a ROOTKIT planted on
- Type: `AUTOCMPLETE SELECTION`
- Required: `TRUE`
## /rootkit disable
`/rootkit disable`
Exit ROOTKIT mode
