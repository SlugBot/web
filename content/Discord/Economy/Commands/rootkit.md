# `/rootkit`
*Module: [[Economy]]*<br>
Enable or disable ROOTKIT mode. A ROOTKIT allows the control of another user's account
## /rootkit enable
`/rootkit enable <target>`<br>
Enable ROOTKIT mode
#### target
User you have a ROOTKIT planted on
- Type: `AUTOCOMPLETE SELECTION`
- Required: `TRUE`
## /rootkit disable
`/rootkit disable`<br>
Exit ROOTKIT mode
