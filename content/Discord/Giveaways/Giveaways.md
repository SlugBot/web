SlugBot allows Servers to host Giveaways using [[raffle]].

![[raffle demo.png]]

The raffle message, raffle duration, number of winners to be drawn, and an optional required role can be customised.

A member can only enter once. If they attempt to enter again they will be prompted with a message asking if they would like to leave the raffle.

After the specified amount of time has passed, the given number of winners will be drawn and listed - pinging each winner to alert them.
