# `/eventlog`
*Module: [[Logging]]*<br>
Manage discord event logging channels
## /eventlog create
`/eventlog create <channel>`<br>
Create a new event logging channel
#### channel
Channel to be used for logging
- Type: `CHANNEL`
- Required: `TRUE`
## /eventlog update
`/eventlog update <channel>`<br>
Update an existing logging channel
#### channel
Channel used for logging
- Type: `CHANNEL`
- Required: `TRUE`
## /eventlog remove
`/eventlog remove <channel>`<br>
Stop logs being sent to a given logging channel
#### channel
Channel used for logging
- Type: `CHANNEL`
- Required: `TRUE`
